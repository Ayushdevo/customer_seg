# Dependency Overview

This project uses the following core dependencies:

- `streamlit`: Dashboard framework for Python.
- `pandas`: Data manipulation and data frame support.
- `numpy`: Numeric array support for model inputs.
- `scikit-learn`: Model serialization and inference.
- `joblib`: Fast model artifact loading.
- `langchain-google-genai`: Integration layer for Google Gemini.
- `python-dotenv`: Optional environment variable management.

Development dependencies can be installed from `requirements-dev.txt`.
