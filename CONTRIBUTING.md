# Contributing to Customer Segmentation

Thank you for your interest in improving this project. This repository follows standard Python conventions and encourages clear, incremental changes.

## How to contribute

1. Fork the repository and create a feature branch from `main`.
2. Make changes in small, meaningful commits.
3. Add or update tests for any functional change.
4. Run `pytest` locally before submitting a pull request.
5. Open a pull request with a clear summary and related issue references.

## Coding standards

* Use consistent formatting and type hints where appropriate.
* Keep business logic separate from presentation code.
* Update documentation and changelog entries for new features.
